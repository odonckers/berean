# Getting help

- **Questions and ideas:** start a thread in [Discussions](https://github.com/odonckers/berean/discussions).
- **Something broken:** open a [bug report](https://github.com/odonckers/berean/issues/new?template=bug_report.yml).
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) describes.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Berean is an independent project. For help with JW Library itself or with your account on the publisher's site, please contact the publisher; we can't help with those.
