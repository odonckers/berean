# proof-assets

Proof screenshots for pull requests, kept out of the app branches. Each PR's images live in `pr-<number>/<name>.png`, and PR bodies link them pinned to a commit SHA:

`https://github.com/odonckers/berean/blob/<sha>/pr-<number>/<name>.png?raw=true`

This orphan branch holds no app code. It is never merged and never deleted, and it is never force-pushed: fetch and rebase before pushing.
