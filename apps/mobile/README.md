# Berean mobile

Expo (SDK 58) app for Berean using a development build (`expo-dev-client`, not Expo Go). It uses Expo Router with native tabs (Read, Studyspace, Search, Library), each tab has its own native stack, and the new architecture is on. The screens show plain placeholder text for now. Light and dark mode follow the system through the expo-router `ThemeProvider`. Real content arrives once the Rust core is wired in.

## Prerequisites

- Node 22.13+ and npm
- JDK 17 and the Android SDK, with an emulator or a device
- iOS: Xcode for local builds. Otherwise iOS will be built later with the EAS free tier.

## Run the dev build

```sh
npm ci
npx expo run:android   # builds and installs the dev client (npm run android)
npm start              # Metro for the installed dev client (expo start --dev-client)
```

`ios/` and `android/` are generated by Continuous Native Generation (CNG) from `app.json` and config plugins. They are gitignored, so don't edit them by hand.

## Checks

```sh
npm run typecheck   # tsc --noEmit (strict)
npm run lint        # expo lint (eslint-config-expo)
npx expo-doctor
```

`eas.json` defines only a `development` profile (dev client, internal distribution). No EAS project is linked yet.

## App identifiers

iOS bundle ID and Android package are both `com.odonckers.berean.mobile`. The Apple app already uses `com.odonckers.berean`.
